# 議会動画の文字起こしと固有名詞辞書 設計

## 1. 目的

水俣市議会の本会議動画（YouTube）を文字起こしして、会議録PDFが出るまでの空白（閉会から約4か月）を埋める。
そのとき、**固有名詞（人名・会派名・地名・施設名・条例名・事業名）の誤りをできるだけ無くす**。

音声認識の誤りの多くは**同音異字**（例: 杉迫 → 杉崎、髙岡 → 高岡）なので、
文字の形ではなく**読み**で照合する仕組みを中心に置く。

## 2. 前提（2026-11-19 の調査で確認）

| 項目 | 内容 | 根拠 |
|---|---|---|
| 動画の配信先 | YouTube（本会議の中継・録画） | https://www.city.minamata.lg.jp/gikai/kiji0033603/index.html |
| 委員会の動画 | 「本会議の中継及び録画配信」とあり、委員会は対象外とみられる | 同上 |
| 動画の位置付け | 「公式記録ではない。公式記録は会議録」 | 同上 |
| 動画の利用条件 | 著作権は水俣市。著作権法の遵守、**出典の記載**、**事実が歪曲される切り抜き・編集・加工をしない** | 同上 |
| 会議録PDF | 閉会から約4か月後に全文公開 | https://www.city.minamata.lg.jp/gikai/list00632.html |

利用条件から、次の2つを設計上の制約にする。

- 文字起こしや要約には、必ず**元動画のURLと時刻**を出典として付ける
- 発言を要約するときも、**前後の文脈を落として意味が変わる抜き出し**をしない

## 3. 方針

**NotebookLM は使わず、文字起こしを自前の処理で行う**（案A）。
NotebookLM は語彙ヒント（辞書）を渡せず、出力の再現性もないため。

## 4. 全体の流れ

```
[固有名詞辞書] ─┬─────────────────────────────┐
                │（語彙ヒント）                 │（照合）
                ▼                              ▼
YouTube動画 → ①音声取得 → ②文字起こし → ③固有名詞の照合 → ④人の確認 → ⑤公開（速報）
                                                              │
                                     会議録PDF（約4か月後）→ ⑥突合 → 公開（確定）
                                                              │
                                     承認した誤記 ──────→ 辞書へ反映
```

## 5. 固有名詞辞書

### 5-1. 収録する種類と正解の出どころ

| 種類 | 例 | 正解の出どころ | 更新のきっかけ |
|---|---|---|---|
| 議員 | 髙岡 朱美（たかおか あけみ） | 議員名簿 https://www.city.minamata.lg.jp/gikai/kiji003736/index.html | 改選・補選 |
| 会派 | 真志会、Ｉ❜ｓ水俣 | 会派構成 https://www.city.minamata.lg.jp/gikai/kiji003739/index.html | 会派の結成・解散・移籍 |
| 執行部（答弁者） | 市長、各部長・課長 | 会議録の出席者欄、市の人事発表 | 4月の人事異動 |
| 委員会 | 総務産業委員会、厚生文教委員会 | 会議録 | 委員会の改編 |
| 条例・議案 | 水俣市旅費支給条例、議第68号 | 例規集（d1-law）、議決結果PDF | 定例会ごと |
| 地名・施設 | 古城、湯の児、総合医療センター | 市サイト、例規集 | まれ |
| 事業・団体 | 「選ばれる水俣」推進事業、JNC | 予算概要PDF、会議録 | 定例会ごと |

### 5-2. 1項目が持つ情報

| 項目 | 内容 | 例 |
|---|---|---|
| 正式表記 | 公開に使う唯一の表記 | 髙岡 朱美 |
| 読み | ひらがな。照合の基準 | たかおか あけみ |
| 種類 | 5-1 の種類 | 議員 |
| よくある誤記 | 過去に承認した誤り | 高岡、高丘 |
| 呼ばれ方 | 会議中の呼称 | 髙岡議員、髙岡朱美君 |
| 有効期間 | いつからいつまで正しいか | 2023-05-01〜2027-04-30 |
| 出典URL | 正解の根拠 | 議員名簿のURL |

**有効期間を必ず持たせる。** 会派の移籍や人事異動のあと、古い会派名・役職で書いてしまう誤りを防ぐため。
照合は、動画の開催日に有効な項目だけを対象にする。

### 5-3. 置き場所

最初は**リポジトリ内のデータファイル**（`packages/` 配下のJSONまたはTS）で持ち、テストで形式を検証する。
件数が増え、管理画面から編集したくなった時点でDBのテーブルに移す。

理由: 初期は数百件規模で、差分をPRでレビューできるほうが誤りに気づきやすい。

## 6. 各段階の設計

### ① 音声取得

- YouTube の公開動画から音声を取得する
- 動画ID・タイトル・公開日・長さを記録する（出典に使う）

### ② 文字起こし（辞書を語彙ヒントとして渡す）

- 文字起こしモデルに、**その会議の開催日に有効な辞書項目**を語彙ヒントとして渡す
- 出力は**発言の区切りごとに開始時刻を持つ**形式にする（出典の時刻に使う）
- 発言者の特定には、議長の指名（「◯◯議員」「◯◯部長」）を手がかりにする

モデルの候補（Gemini の音声入力、Whisper など）は、同じ動画で辞書あり・なしの誤り件数を比べて決める（8章）。

### ③ 固有名詞の照合

1. **正規化**: 全角・半角（NFKC）、旧字・異体字（髙→高 等）を、照合用にだけそろえる。公開する表記は辞書の正式表記に戻す
2. **候補の抽出**: 形態素解析で固有名詞らしい語と、その読みを取る
3. **読みで照合**: 候補の読みと、辞書の読み・呼ばれ方を比べる
4. **判定**

| 判定 | 条件 | 処理 |
|---|---|---|
| 確定 | 表記が辞書の正式表記・誤記に完全一致 | 正式表記に置き換えて確定 |
| 候補 | 読みが近い辞書項目がある | 置換候補として④へ |
| 不明 | 近い項目がない | 新しい固有名詞の可能性として④へ |

### ④ 人の確認

- 「候補」「不明」を一覧にし、承認・却下・辞書へ新規登録を選ぶ
- 承認した誤記は辞書の「よくある誤記」に追加し、次回から自動で確定させる
- 初期は Markdown やスプレッドシートで確認し、量が増えたら管理画面に画面を作る

### ⑤ 公開（速報）

- 表示に「速報（動画から作成。公式記録ではありません）」と出す
- すべての引用に元動画のURLと時刻を付ける

### ⑥ 会議録との突合（確定）

- 会議録PDFが出たら、同じ発言を突き合わせて表記の差を検出する
- 差があった固有名詞は辞書の誤記として記録する
- 表示を「確定（会議録で照合済み）」に切り替え、出典に会議録を追加する

## 7. 範囲外（この設計では扱わない）

- 委員会の文字起こし（動画が配信されていないとみられるため）
- 議員別賛否のデータ化（議会だよりPDFから別途取り込む。現在のDBは会派別賛否 `faction_stances` のみ）
- 議案本文の取得（調査結果どおり、予算は財政課PDF、条例は例規集・会議録で補う）

## 8. 進め方

| 段階 | 内容 | 完了の条件 |
|---|---|---|
| 1 | 辞書の初期データ（議員16人・会派・委員会・執行部） | 公式ページから作成し、テストで形式を検証 |
| 2 | 1本の動画で文字起こしを試す（辞書あり・なし） | 固有名詞の誤り件数を比較できる |
| 3 | 照合処理（③）を作る | 段階2の出力で「確定・候補・不明」に分けられる |
| 4 | 会議録との突合（⑥）で精度を測る | 会議録が出ている過去の定例会1回分で誤り率を出す |
| 5 | 公開の仕組み（⑤）と確認の画面（④） | 段階4の誤り率を見て判断 |

段階4は、**会議録がすでに公開済みの過去の定例会**（例: 令和7年9月定例会）で行う。
会議録を正解として使えるので、動画からの文字起こしの精度を数字で測れる。
