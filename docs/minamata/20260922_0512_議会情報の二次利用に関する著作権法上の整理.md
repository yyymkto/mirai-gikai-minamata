## 1. 結論

本サービスが必要とする利用のほとんどは、**水俣市の許諾がなくても著作権法上適法に行える**。

| 扱うもの | 結論 | 根拠 |
| :-- | :-- | :-- |
| 議案番号・件名・提出者・付託委員会・議決結果・日付 | **自由に利用可** | そもそも著作物でない（事実） |
| 会派別賛否（議会だよりの表などから抽出した事実） | **自由に利用可**（表のレイアウトを模倣しない限り） | 同上 |
| 成立した条例の本文 | **自由に利用可** | 著作権法13条1号（法令は権利の目的とならない） |
| 議案（条例案）の条文 | **ほぼ自由に利用可** | 表現の選択の幅が狭く著作物性を認めがたい。議決・公布後は13条1号で完全に自由 |
| 議会での発言（会議録・中継の音声内容） | **学説が割れる。**1項説なら自由、2項説ならウェブ掲載は不可 | 著作権法40条1項／2項（3.3） |
| 議会での発言を**情報解析**（AIで分類・要約の材料に）する | **自由に行える** | 著作権法30条の4第2号 |
| 解析結果として**AIが独自の表現で書いた解説** | **自由に公開できる** | 原著作物の表現を再現しない限り、そもそも複製・翻案に当たらない |
| 議会だより・広報資料の**転載** | **不可として扱う**（市サイトの表示を32条2項の禁止表示と解する）。ただし**引用**（32条1項）は可 | 著作権法32条（3.4・4章） |
| 議会中継の**映像そのもの** | 水俣市に帰属（職務著作）。転載不可、YouTube の埋め込み・リンクで対応 | 著作権法15条1項 |

水俣市サイトの著作権表示は「私的使用のための複製」「引用」など**著作権法上認められた利用を自ら除外している**（2章）。したがって本書の整理は、市の表示とも矛盾しない。

- 市への働きかけは「**使わせてください**」という許諾のお願いではなく、「**議会データもオープンデータとして公開しませんか**」という提案にする。水俣市は既に**CC BY 4.0 で5件のオープンデータを公開している**（6.4）ので、同じ枠組みに議会データを加える提案として説得力がある。
- ただし**議会での発言の扱いだけは慎重を要する**（3.3）。ここは学説が真っ二つに割れており、設計で回避する（7章）。
- 水俣市固有の事情として、**水俣病に関わる請願・陳情や発言には健康に関する情報（要配慮個人情報）が含まれ得る**。著作権とは別に、個人情報の扱いに特に注意する（5章）。

## 3. 対象別の逐条検討

### 3.1 事実データ — 著作物ではない

著作権法2条1項1号は著作物を「思想又は感情を**創作的に表現**したもの」と定義する。以下は事実であって思想・感情の創作的表現ではないため、著作物ではなく、著作権は及ばない。

- 議案番号、議案名、提出日、提出者、付託委員会、委員会審査結果、議決日、審議結果
- 定例会・臨時会の会期（開会日・閉会日）
- 議員の氏名・会派・所属委員会
- 会派別の賛否（○×）

**編集著作物（12条1項）の問題**は残るが、議決結果の一覧は議案番号順などの機械的な配列であり、素材の選択・配列に創作性を認めるのは難しい。念のため、**取り込んだ事実を自前のデータモデルに再構成し、元資料の表レイアウトを模倣しない**運用にすれば、編集著作物の議論も回避できる。

> **設計上の帰結**: 議案・議決結果・会派別賛否は、**資料から抽出して DB（`bills`・`faction_stances` など）に持ち、自サービスの形式で表示してよい**。出典表示はマナーとして必ず行う（法的義務ではないが、信頼性のために必須）。

### 3.2 条例・条例案の本文 — 13条1号

```
著作権法第13条 次の各号のいずれかに該当する著作物は、この章の規定による権利の目的となることができない。
 一 憲法その他の法令
 二 国若しくは地方公共団体の機関、独立行政法人又は地方独立行政法人が発する告示、訓令、通達その他これらに類するもの
 三 裁判所の判決、決定、命令及び審判 …（略）
 四 前三号に掲げるものの翻訳物及び編集物で、国若しくは地方公共団体の機関 …が作成するもの
```

**条例・規則は1号の「法令」に含まれる**というのが通説である。したがって、成立した水俣市の条例本文は著作権の対象外であり、全文を掲載しても改変しても構わない（水俣市例規集の内容も同様）。

議決前の**条例案**は厳密には「法令」ではない。しかし条例案の条文は法制執務の作法に厳格に縛られており表現の選択の幅がほぼ無い（ありふれた表現）ため、著作物性を認めがたい。加えて議決・公布されれば1号で完全に自由になる。**実務上のリスクは低い。**

予算書・決算書の数値、新旧対照表も同様に事実・データである。

> **設計上の帰結**: 条例本文や議案本文を議案の `knowledge_source` として保存し、AI のコンテキストに使うことに、著作権上の障害はない。

### 3.3 議会での発言 — 40条。ここだけが本当の論点

まず**著作権が誰に帰属するか**。一般財団法人 地方自治研究機構の自治体法務 Q&A は次のように整理する。

- 創作性のある質疑応答・答弁は著作物として保護される
- **議員**の質疑・討論 → **その議員個人**が著作者。著作権は議員に帰属する
- **市長・市職員**の答弁 → 職務著作（15条1項）として**地方公共団体（水俣市）**に帰属
- 議会中継の**映像** → 議会事務局職員が作成するため職務著作。水俣市に帰属
- 「議会」自体は権利能力を持たないため、議会に著作権が帰属することはない

つまり市サイトの「著作権は、水俣市に帰属します」という包括表示は、**会議録に含まれる議員の発言部分については当てはまらない**（議員個人に帰属する）。

次に**40条による権利制限**。条文は以下のとおり。

```
著作権法第40条（公開の演説等の利用）
第1項 公開して行われた政治上の演説又は陳述並びに裁判手続及び行政審判手続における公開の陳述は、
       同一の著作者のものを編集して利用する場合を除き、いずれの方法によるかを問わず、利用することができる。
第2項 国若しくは地方公共団体の機関、独立行政法人又は地方独立行政法人において行われた公開の演説又は陳述は、
       前項の規定によるものを除き、報道の目的上正当と認められる場合には、新聞紙若しくは雑誌に掲載し、
       又は放送し、有線放送し、地域限定特定入力型自動公衆送信を行い、若しくは放送同時配信等を行うことができる。
```

**この2項の差が決定的である。**

| | 適用される条項 | 許される利用 |
| :-- | :-- | :-- |
| 1項が適用されるなら | 40条1項 | **「いずれの方法によるかを問わず」利用可。ウェブ掲載も含む。** ただし「同一の著作者のものを編集して利用する場合」は除外 |
| 2項のみなら | 40条2項 | 報道目的で、新聞・雑誌への掲載か放送等に限られる。「放送等」は放送事業者向けの概念であり、**一般のウェブサイトへの掲載は含まれない** |

そして学説・実務は割れている。

**1項適用を認める立場**（国立国会図書館）
国会会議録検索システムのヘルプ「利用条件・免責事項」は、発言の著作権は個々の発言者に帰属するとしたうえで、以下の権利制限規定が適用される場合は許諾なく利用できると明記している。

> 私的使用のための複製、引用、**政治上の演説又は陳述に該当する箇所の利用**、報道、**電子計算機による情報解析** 等

国の機関が公式に「政治上の演説又は陳述に該当する箇所」として40条1項の適用を認めている点は、実務上の強い後ろ盾になる。

**1項適用を否定する立場**（地方自治研究機構）

> 議会における質疑応答や答弁等については同条1項の適用はないという見解が有力

理由は明示されていないが、体系解釈としては「40条2項がわざわざ『地方公共団体の機関において行われた公開の演説又は陳述』を別に規定している以上、議場での発言は2項の守備範囲であって1項の『政治上の演説』とは区別される」という理解と思われる。同機構は、ウェブへのアップロードには原則として議員の許諾が必要であり、**議会であらかじめ申し合わせをしておくのがよい**と実務的な助言をしている（なおこの Q&A は2013年のもので、令和3年改正前の条文を前提にしている点に留意）。

**評価**

条文を素直に読めば、2項の「前項の規定によるものを除き」は、**議会での発言であっても「政治上の演説又は陳述」に当たるものには1項が優先適用される**という構造を示している。市長の施政方針や議員の討論は政治的主張の表明そのものであり、1項に当たると解する余地は十分ある。他方で、事務的な議事進行の発言や事実確認の答弁は「政治上の演説又は陳述」とは言い難い。

**要するに、発言の性質によって1項に当たるものと当たらないものが混在する**というのが実態に近く、会議録を一律に扱う判断はどちらの立場でもリスクが残る。

> **設計上の帰結（7章で詳述）**
> - 会議録の**全文をそのまま掲載しない**。原文は水俣市議会の会議録検索システム・議会中継（YouTube）へリンクする。
> - **議員個人の発言だけを集めたページを作らない。** これは40条1項が適用される場合でも、ただし書き「同一の著作者のものを編集して利用する場合」に該当し、明確に適用除外になる。**議員別の発言アーカイブは、40条のどちらの説に立っても作れない。**
> - 解析（30条の4）と、AI が独自表現で書いた要約・論点整理の公開（3.6・3.7）に軸足を置く。これは40条の解釈に依存しない。

### 3.4 議会だより・広報資料 — 32条

```
著作権法第32条
第1項 公表された著作物は、引用して利用することができる。この場合において、その引用は、公正な慣行に合致するものであり、
       かつ、報道、批評、研究その他の引用の目的上正当な範囲内で行なわれるものでなければならない。
第2項 国若しくは地方公共団体の機関 …が一般に周知させることを目的として作成し、その著作の名義の下に公表する広報資料、
       調査統計資料、報告書その他これらに類する著作物は、説明の材料として新聞紙、雑誌その他の刊行物に転載することができる。
       ただし、これを禁止する旨の表示がある場合は、この限りでない。
```

「みなまた市議会だより」は2項の「広報資料」に当たる。市サイトの著作権表示は「無断で複製・転用することはできません」とし、許諾の問い合わせ先を示している（2章）。これが2項ただし書きの「**これを禁止する旨の表示**」に当たるかは解釈の余地があるが、**当たると解して保守的に運用する**。したがって **32条2項による転載はしない。**

一方、**32条1項の引用は使える。** 市の表示自体も「引用」を明示的に除外している。以下の要件を満たせば適法である。

- 引用する必然性があること
- 自己の著作物と引用部分が明瞭に区別されていること
- 自己の著作物が主、引用部分が従であること（主従関係）
- 引用の目的上正当な範囲内であること
- 出所を明示すること（48条1項）

> **設計上の帰結**: 議会だよりから**会派別賛否という事実を抽出して自前の表（`faction_stances`）にする**のは転載でも引用でもなく、そもそも著作権が及ばない（3.1）。議会だよりの文章そのものを載せたい場合のみ、引用の要件を厳格に満たす形にする。議会だよりの PDF をリポジトリやサイトに置いて再配布しない。

### 3.5 議会中継の映像 — 水俣市に帰属

職務著作（15条1項）として水俣市に著作権が帰属する。**動画ファイルのダウンロード・転載・再配信は不可。** 水俣市の YouTube 配信へリンクするか、YouTube の埋め込み機能（公式が提供する埋め込み手段）を使う。

なお発言の**内容**（言語の著作物）と映像（映画の著作物）は別の著作物であり、内容の扱いは3.3の議論による。

### 3.6 AI による情報解析 — 30条の4

```
著作権法第30条の4
著作物は、次に掲げる場合その他の当該著作物に表現された思想又は感情を自ら享受し又は他人に享受させることを
目的としない場合には、その必要と認められる限度において、いずれの方法によるかを問わず、利用することができる。
ただし、当該著作物の種類及び用途並びに当該利用の態様に照らし著作権者の利益を不当に害することとなる場合は、この限りでない。
 二 情報解析（多数の著作物その他の大量の情報から、当該情報を構成する言語、音、影像その他の要素に係る情報を抽出し、
   比較、分類その他の解析を行うことをいう。…）の用に供する場合
```

**議案 PDF や会議録を取得して LLM に投入し、論点を分類・抽出・要約の材料にする行為は、典型的な「情報解析」である。** 国会図書館も権利制限規定の一つとして明記している。

ただし但し書きに注意。「著作権者の利益を不当に害する」場合は適用されない。議会情報については、市が販売しているわけでも市場が存在するわけでもないため、不当に害する余地は乏しい。

**重要な限界**: 30条の4は「思想又は感情を自ら享受し又は他人に享受させることを目的としない場合」に限られる。**解析結果として原文をそのまま読ませる**なら、それは享受目的なので30条の4では正当化できない。あくまで**解析の過程での複製**を正当化する規定である。

> **設計上の帰結**: 取り込み・解析（管理画面の AI 情報収集、議案解説の生成など）の過程で原文を一時的に保持することは適法。**原文をそのままユーザーに配信しない**設計にすることで、30条の4の枠内に収まる。

### 3.7 AI が生成した解説の公開 — そもそも著作権が及ばない

著作権は**表現**を保護し、**アイデア・事実**は保護しない。

- 「議第○号は印鑑条例の一部改正で、可決された」→ 事実。自由
- 「この改正はマイナンバーカードでのコンビニ交付に対応するもので、市民にとっては手数料が変わる点が要点」→ AI（または運営者）が原文を読んだうえで**自分の言葉で書いた表現**。新たな著作物であり、原文の複製でも翻案でもない

翻案（27条）に当たるのは、原著作物の**表現上の本質的特徴を直接感得できる**場合である。原文の言い回しを再現せず、事実と論点だけを抽出して独自に構成した解説は、これに当たらない。

**これが本サービスの中核であり、法的に最も安全な領域でもある。** 「議会の一次資料を読み解いて、市民に分かる言葉で説明し直す」という行為そのものが、著作権法上ほぼ自由に行える。

なお文化庁「AIと著作権に関する考え方について」（2024年3月）は、生成・提供段階については通常の著作権侵害の枠組み（類似性＋依拠性）で判断するとしており、上記の整理と整合する。

## 4. 市サイトの著作権表示の法的効力

水俣市の表示は、沼津市のような「二次利用を禁止」という包括的な書き方ではなく、「著作権法上認められた場合を除き、無断で複製・転用することはできません」という書き方である。つまり**権利制限規定による利用を市自身が認めている**。いずれにせよ、以下はサイトの表示で覆せない。

| 覆せないもの | 理由 |
| :-- | :-- |
| 32条1項の引用 | 権利制限規定であり、権利者の一方的意思表示で排除できない |
| 30条の4の情報解析 | 同上 |
| 40条の公開の演説等の利用 | 同上 |
| 13条により著作権が発生しないもの（法令等） | そもそも権利がない |
| 事実・アイデアの利用 | そもそも著作物でない |

**覆せるもの**は、条文自身が「禁止する旨の表示がある場合はこの限りでない」と定めているもの（32条2項の転載など）だけである。本書では、市の表示がこれに当たると解して転載をしない（3.4）。

サイト表示が法的意味を持つのは、(a) 上記の明文の除外にあたる場合、(b) 利用規約への同意という**契約**が成立している場合、の2つ。市サイトは閲覧にあたり同意を求めるフローを持たないため、(b) の契約構成は成り立ちにくい。

とはいえ、法的に適法であることと、市との関係を良好に保つことは別問題である。**法的には許諾不要でも、事前に一報を入れて関係を作るほうが、長期的にはデータ提供の改善につながる**（8章）。

## 5. 個人情報・名誉毀損など著作権以外の論点

著作権をクリアしても以下は別途検討が必要である。

| 論点 | 内容 | 対応 |
| :-- | :-- | :-- |
| 議員の個人情報 | 市サイトの議員名簿には**住所**・職業・年齢が含まれる | **住所は取り込まない。** 氏名・会派・政党名・所属委員会に限定する |
| 請願者・陳情者の氏名 | 請願・陳情の提出者名 | 公開情報だが、サービス上で強調しない。氏名は取り込まない方針を推奨 |
| **水俣病に関わる情報** | 水俣病の認定・補償・健康被害に関わる請願・陳情や発言には、**病歴・健康状態など要配慮個人情報**が含まれ得る。地域社会での差別・偏見の歴史的経緯もある | 個人を特定し得る記述を取り込まない・生成させない。議案・請願の要点は制度や施策の内容に絞って書く。AI 生成の解説は公開前に人が確認する |
| 会議録の表記 | 会議録検索システムは JIS 第2水準までの文字で表示しており、人名等が原本と異なる場合がある旨を明記している | 人名等の表記揺れに注意し、原本（会議録）へのリンクを添える |
| 名誉毀損・議員の評価 | AI が議員や会派の姿勢を要約・評価する場合 | 事実の摘示と論評を区別する。断定を避け、根拠となる一次資料へリンクする。誤りの申告・訂正の窓口を設ける |
| 公職選挙法 | 選挙期間中の特定候補への言及 | 選挙期間中は議員・会派個別の評価表示を控える運用を検討 |
| 誤情報のリスク | AI 生成の解説が誤って市政の理解を歪める | 人のレビューを公開の必須ゲートにする。誤りの訂正フローを用意する |
| AIインタビューの回答 | 市民の意見に個人情報や第三者の情報が含まれ得る | 既存のモデレーションと公開同意フロー（本家由来）を維持する。オープンデータ提供は `features.openData` を有効にするまで行わない |

## 6. 制度的な後押し

### 6.1 議事公開の原則

地方自治法115条1項は議会の会議を公開と定め、同法123条は議長に会議録の作成を義務づける。総務省は、この規定の趣旨を「住民の求めに応じて閲覧させることなどにより、議事公開の原則を全うすること」とし、**会議録のホームページ上での公開等に積極的に取り組むことが重要**としている。

議会情報は「市民が知るために」制度上公開されている。二次利用を過度に制限する運用は、この趣旨と整合しない。

### 6.2 オープンデータ基本指針

政府の「オープンデータ基本指針」（2017年決定、2024年7月改正）は、国・自治体が保有するデータを機械判読可能な形式で、二次利用可能なルールのもとで公開することを原則としている（オープンデータ・バイ・デザイン）。

### 6.3 公共データ利用規約（第1.0版）

デジタル庁の「公共データ利用規約（第1.0版）」（2024年7月）および従来の「政府標準利用規約（第2.0版）」は、いずれも **CC BY 4.0 と互換**の利用条件を標準とする。

### 6.4 【重要】水俣市自身が CC BY 4.0 でオープンデータを公開している

水俣市はオープンデータのページで、**クリエイティブ・コモンズ・ライセンス表示 4.0 国際（CC BY 4.0）**のもと、商用利用も含めてデータを公開している。公開中のデータセットは次の5件である（2026-09-22 時点）。

- 指定緊急避難所一覧
- 公共施設一覧
- 子育て施設一覧
- 観光施設一覧
- 地域・年齢別人口

**議会関連のデータセットは0件**である。

つまり「CC BY 4.0 でデータを出す」ための市の規約・運用は既にあり、**議会データを同じ枠組みに加えるだけ**でよい。**これは市への提案において最も効く材料である**（8章）。熊本県内のオープンデータは BODIK ODCS や「くまもとデータ連携基盤」などのカタログ基盤でも公開されている。

### 6.5 先行事例

- **chiholog（地方議会議事録横断検索）** — 798自治体の会議録を収集して全文検索・単語頻度分析を提供し、VLED 利活用・普及委員会から表彰を受けた。サイト上で著作権法13条に言及して法的立場を明示していた（2016〜2019年、現在は終了）
- **地方議会会議録コーパスプロジェクト（local-politics.jp）** — 会議録の横断検索・自動要約・意見抽出の研究基盤
- **国立国会図書館 国会会議録検索システム API** — 会議単位・発言単位でデータ取得可能な公式 API
- **みらい議会の地方版（川崎市・沼津市など）** — 本リポジトリの派生元。各地の議会情報を同様の方針で扱っている

議会会議録を収集・解析して公開するサービスは既に複数存在し、表彰まで受けている。**前例のない挑戦ではない。**

## 7. 設計への落とし込み

法的整理を踏まえた実装・運用ルール。

### 7.1 やってよいこと（許諾不要）

| # | 内容 | 本リポジトリでの該当箇所 |
| :-- | :-- | :-- |
| A1 | 議案番号・件名・提出者・付託委員会・議決結果・日付を抽出して DB に保持し、自サービスの形式で表示する | `bills`、`council_sessions`、`committees` |
| A2 | 会派別賛否を議会だよりなどから抽出し、自前の表で表示する | `factions`、`faction_stances` |
| A3 | 条例本文・議案本文を取得して保持し、AI のコンテキストに使う | 議案の `knowledge_source`、`pdf_url` |
| A4 | 会議録・議案を LLM に投入して論点抽出・分類・要約の材料にする（30条の4） | 管理画面の AI 情報収集、議案解説の生成 |
| A5 | AI（または運営者）が独自の表現で書いた解説・論点整理を公開する | `bill_contents`（ふつう／難しい） |
| A6 | 水俣市の公式ページ・会議録検索システム・議会中継（YouTube）へリンクする | `council_url`、`councilBillsDetailUrl` |
| A7 | 議会だよりの文章を、引用の要件（明瞭区別・主従関係・出所明示）を満たす形で引用する | 議案解説本文 |

### 7.2 避けること（設計上の制約）

| # | 制約 | 理由 |
| :-- | :-- | :-- |
| **N1** | **議員個人の発言だけを集めたページ・アーカイブを作らない** | 40条1項ただし書き「同一の著作者のものを編集して利用する場合」に該当。**1項説・2項説のいずれに立っても不可** |
| N2 | 会議録の全文をそのままユーザーに配信しない | 40条の解釈が割れているため。原文は会議録検索システムへリンクする |
| N3 | 議会中継の映像ファイルをダウンロード・転載・再配信しない | 職務著作として水俣市に帰属。YouTube のリンク・埋め込みで対応 |
| N4 | 議会だより・議案 PDF を丸ごと再配布しない（リポジトリにも置かない） | 32条2項を禁止表示ありとして運用するため |
| N5 | 議決結果の資料の表レイアウトをそのまま模倣しない | 編集著作物性の議論を回避 |
| N6 | 議員の住所を取り込まない。請願者・陳情者の氏名、水俣病に関わる個人の情報を取り込まない | 個人情報・要配慮個人情報 |
| N7 | 30条の4で取得した原文を、解析目的を超えて配信しない | 「享受目的」になると30条の4の枠外 |

> **N1 は一般質問の扱いに直接効く。** 一般質問を「議案やテーマごとの論点」として扱うのは問題ないが、「○○議員の質問一覧」というページ構成は避ける。議員ページを作る場合は、**発言そのものではなく、会派・所属委員会・賛否（事実）へのリンク集**に留める。

### 7.3 データの持ち方

- 会議録の全文は DB に保存しない。解析が必要なときは会議録検索システムから取得して LLM に投入し、**抽出された論点・要約のみを永続化**する（N2・N7）。
- 議会だより・議案 PDF は、解析のためにローカルで一時的に扱うのはよいが、**リポジトリにコミットしない**（N4）。取り込み作業で使った PDF は作業後に削除するか、`.gitignore` の対象にする。

### 7.4 サイトへの表示

- 各議案ページに**出典**（水俣市議会の該当ページ URL）を必ず表示する
- 「本サービスは水俣市および水俣市議会の公式サービスではありません」を常時表示する（あわせて、チームみらいの公式サービスではない旨の表示を維持する）
- 会議録に由来する情報には、出典が水俣市議会の会議録検索システムである旨と、原文へのリンクを添える
- 解説が AI により生成されたものであること、および人のレビューを経ていることを明示する
- 誤りの指摘を受け付ける窓口を設ける（既存の「問題を報告する」フォーム）

## 8. 市への働きかけ

実装は**止めない**（7章の制約下で適法に進められる）。市には別のトラックで**オープンデータ化を提案**する。

**提案の骨子**

1. 議案の一覧・議決結果（会派別賛否を含む）を CSV で公開してほしい（項目案: 定例会・議案番号・件名・種別・提出者・付託委員会・委員会審査結果・議決日・議決結果・議案本文 URL）
2. **水俣市は既に CC BY 4.0 でオープンデータを公開している**（6.4）。同じ規約・同じページに議会データを加えるだけでよい
3. 政府の「オープンデータ基本指針」「公共データ利用規約」が CC BY 互換を標準としている（6.2・6.3）
4. 市サイトの著作権表示について、議会情報（条例本文や議員の発言など、市に著作権が帰属しないものを含む）の扱いを明確にしてほしい

**あわせて、事前に一報を入れる。** 法的には許諾不要でも、「こういうサービスを作ります、出典は必ず明記します、誤りがあれば直します」と先に伝えておくことは、後の関係づくりに効く。**許可を求める形にはしない**（断られたら適法な利用まで自縛することになるため）。窓口は水俣市議会事務局とする。

なお、市の見解が「二次利用は一切不可」であった場合でも、7.1 の A1〜A7 は著作権法上適法である。**その場合は本書の整理を示して対話する**という構えでよい。

## 9. 残る不確実性

| # | 論点 | 状態 | 対応 |
| :-- | :-- | :-- | :-- |
| U1 | 議会での発言に40条1項が適用されるか | **学説が割れている。判例を確認できていない** | 7.2 の N1・N2 で回避する設計とし、解釈に依存しない |
| U2 | 議決結果の資料に編集著作物性が認められるか | 創作性は乏しいと考えるが確定的でない | N5 でレイアウトを模倣しないことで回避 |
| U3 | 30条の4の但し書き「著作権者の利益を不当に害する」の射程 | 議会情報には市場がないため該当しにくいと考える | N7 で享受目的の利用を避ける |
| U4 | 市サイトの著作権表示が32条2項の「禁止する旨の表示」に当たるか | 「無断で複製・転用することはできません」は禁止表示と解し得るため、当たると解して保守的に運用 | 転載はせず引用に留める |
| U5 | 条例案（議決前）の著作物性 | 否定的に解するが確定的でない | 議決後は13条1号で完全に自由。議決前の議案は要約中心に扱う |

**公開前に必ず行うこと**

- 著作権・情報法に明るい**弁護士によるレビュー**（本書と、実際の画面・データフローを見せる）
- 利用規約・プライバシーポリシー・免責事項の整備（本家の2026年7月改訂版をもとにしているため、水俣版の運営実態に合わせて確認する）
- 誤り訂正・削除依頼の受付フローの整備

**本書は法的助言ではない。** 実サービスの公開判断は専門家のレビューを経ること。
